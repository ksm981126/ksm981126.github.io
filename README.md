# 급여 달력

개인 근무 기록과 급여를 달력으로 관리하는 오프라인 우선 웹앱입니다. GitHub Pages에 올려서 PC와 모바일에서 같은 주소로 사용할 수 있고, 기기에 자동 저장하고 JSON 백업 파일로 다른 기기에 기록을 옮길 수 있습니다.

## 주요 기능

- 달력에서 날짜를 눌러 출근 기록 입력
- 기본 시급, 출근/퇴근 시간, 휴게시간 설정
- 일별 시급, 출근 시간, 퇴근 시간, 휴게시간 수정
- 5인 미만/5인 이상 사업장 설정
- 주휴수당, 연장근로, 야간근로, 휴일근로 예상 계산
- 주휴수당은 월 총시간을 나누지 않고 월~금 소정근로일 개근 여부를 주별로 확인해 주휴일인 일요일이 속한 근무월에 반영
- 법정 근로시간 기준 주 단위 알림
- 주별 연장근로 시간 표시
- 토요일 근무는 주 40시간을 넘는 구간부터 연장근로로 계산
- 달력에는 날짜별 연장·야간 시간만 표시
- 월 급여 상세에 연장근로 총액과 야간가산 총액 표시
- 월 총 근무시간, 기본근로시간, 실근로 기본급과 기본급성 합계 표시
- 공휴일, 대체공휴일, 주말 색상 표시
- 2026년부터 다시 공휴일인 제헌절과 노동절 및 해당 대체공휴일 반영
- 기존에 제헌절을 수동 대체공휴일로 기록했어도 자동 유급휴일로 분류
- 평일 공휴일 유급휴일 계산
- 월급일 설정 및 달력 표시
- 월급일이 공휴일/주말이면 이전 평일로 자동 조정
- 전월 근무분을 다음 달 월급일에 받는 방식으로 표시
- 2026년 4대보험 요율과 국세청 근로소득 간이세액표 기반 세후 예상
- 입사일 기준 연차/휴가 계산
- 휴가 사용 기록 및 남은 휴가 표시
- 급여 달력 근무구분에서 대체 공휴일 8시간 유급 처리
- 월별 급여 조회
- 전체 조회에서 연간 급여와 월별 그래프 표시
- 업무일지 달력 전환
- 업무일지 안에서 현장 기록과 영수증을 탭으로 분리
- 날짜별 현장명, 시작/종료 시간 선택, 맡은 업무 기록
- 모바일 현재 위치, GPS 정확도, 기록 시각 저장 및 웹 지도 확인
- 영수증 탭에서 사용 내용과 사용금액, 영수증 촬영·선택
- 날짜별 영수증 여러 건 추가
- 영수증 사진을 선택하면 한글·영문·숫자를 자동 추출해 편집 가능한 텍스트로 저장
- 글자 추출에 성공하면 사진은 즉시 삭제되고 텍스트·사용 내용·금액만 기기에 저장하고 파일로 백업
- 설정 메뉴에서 버전별 업데이트 내역 확인
- 설치/점검/배터리 교체/UPS 교체/철거/유급휴가 업무 중복 선택
- 하루 여러 현장 기록
- 현장 업무가 없는 날의 사무실 기록
- 앱 잠금 비밀번호 설정
- JSON 파일 백업/가져오기
- 모바일 홈화면 추가 가능한 PWA 방식

영수증 글자 추출은 브라우저 안에서 처리됩니다. 인식 프로그램과 언어 파일을 불러올 때 인터넷 연결이 필요합니다. 추출된 글자는 오프라인에서도 볼 수 있고, 추출에 실패한 경우에만 다시 시도할 수 있도록 사진이 임시로 남습니다.

## 2026년 공제 계산 기준

- 국민연금 근로자 부담률 4.75%
- 건강보험 근로자 부담률 3.595%
- 장기요양보험료는 건강보험료의 13.14%
- 고용보험 근로자 부담률 0.9%
- 소득세는 국세청 근로소득 간이세액표의 월 급여 구간과 부양가족 수 적용
- 국민연금·건강보험은 설정의 `기준 보수월액`, 고용보험과 소득세는 월 과세급여 기준으로 예상

실제 회사 신고 보수월액, 비과세 항목, 부양가족 신고 및 원 단위 처리에 따라 급여명세서와 소액 차이가 날 수 있습니다.

`기본급성 합계`는 실근로 기본급에 주휴, 유급휴일, 대체공휴일, 유급휴가를 더한 비교용 금액입니다. 회사마다 급여명세서의 기본급 묶음 방식이 다를 수 있습니다. 야간근로가 22:00~06:00에 포함되면 5인 이상 사업장 기준 법정 야간가산 예상액은 실제 명세서에 없어도 표시합니다.

연장근로수당 월 합계는 실제 급여명세서와 같은 방식으로 10원 단위 반올림합니다.

## 사용 주소

현재 배포 주소:

```text
https://ksm981126.github.io/
```

다른 사람이 이 프로젝트를 복사해서 사용할 경우, 자기 GitHub Pages 주소로 바꿔서 사용하면 됩니다.

## 기본 사용 방법

1. 앱 주소에 접속합니다.
2. 처음 실행하면 왼쪽 설정 메뉴에서 기본 정보를 입력합니다.
   - 시급
   - 기본 출근 시간
   - 기본 퇴근 시간
   - 휴게시간
   - 월급일
   - 입사일
   - 사업장 규모
   - 세후 예상 사용 여부
3. 달력에서 근무한 날짜를 누릅니다.
4. 필요한 경우 그날의 시급, 출근/퇴근 시간, 휴게시간을 수정합니다.
5. 저장하면 달력에 출근 표시가 생기고 급여 예상에 반영됩니다.
6. `급여 조회`에서 월별 급여 또는 전체 조회 그래프를 확인합니다.
7. `업무일지`를 누르면 업무일지 달력으로 전환됩니다.
8. 업무일지 달력에서 날짜를 누르면 현장명, 작업기간, 맡은 업무를 기록할 수 있습니다.

## 모바일에서 사용하기

휴대폰 브라우저에서 앱 주소를 연 뒤 홈화면에 추가하면 앱처럼 사용할 수 있습니다.

### Android Chrome / Samsung Internet

1. 앱 주소 접속
2. 브라우저 메뉴 열기
3. `홈 화면에 추가` 선택
4. 홈화면 아이콘으로 실행

### iPhone Safari

1. 앱 주소 접속
2. 공유 버튼 선택
3. `홈 화면에 추가` 선택
4. 홈화면 아이콘으로 실행

## PC에서 사용하기

브라우저에서 앱 주소를 열어 사용하면 됩니다.  
sync-v44부터 Google Drive 연결과 자동 동기화는 사용하지 않습니다. 기존 Drive 파일은 삭제하지 않습니다.

## 데이터 백업과 이동

1. 기록이 있는 기기에서 설정의 `백업 내보내기`를 누릅니다.
2. 내려받은 JSON 파일을 새 기기나 다른 기기로 전달합니다.
3. 같은 앱 주소에서 `가져오기`로 파일을 선택합니다.
4. 기록 교체를 확인하면 백업의 출근·업무일지·영수증·설정이 복원됩니다.

기록은 브라우저와 사이트 주소별로 따로 저장됩니다. GitHub 주소와 Sites 주소의 기록도 별개입니다. 주로 사용하는 주소를 유지하고, 휴대폰 교체나 브라우저 데이터 삭제 전에 파일을 백업해주세요. PC와 모바일 사이의 자동 동기화는 제공하지 않습니다.

## 다른 사람이 사용하려면

프로젝트를 복사해 정적 호스팅에 올리면 됩니다. Google OAuth 설정은 필요하지 않습니다.

## 오프라인과 캐시

이 앱은 오프라인에서도 열 수 있도록 서비스 워커 캐시를 사용합니다.  
새 버전이 배포되면 이전 오프라인 캐시는 자동으로 삭제되도록 구성되어 있습니다.

화면이 예전 버전으로 계속 보이면:

1. 앱을 완전히 종료 후 다시 열기
2. 그래도 안 되면 홈화면 아이콘 삭제 후 다시 추가
3. 마지막으로 브라우저의 사이트 데이터에서 `ksm981126.github.io` 데이터를 삭제

주의: 사이트 데이터 삭제 전에는 반드시 JSON 파일을 내보내 기록을 보관해주세요.

## 계산 관련 주의사항

이 앱의 급여, 세금, 수당 계산은 개인 참고용 예상치입니다.  
실제 급여, 공제, 세금, 연차 계산은 회사 규정, 근로계약, 정부 고시, 비과세 항목, 부양가족, 신고 방식 등에 따라 달라질 수 있습니다.

정확한 정산이 필요한 경우 회사 급여 담당자, 노무사, 세무사 또는 정부 공식 자료를 확인해야 합니다.
